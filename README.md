# 🐍 DSA in Python — My Learning Journey

A structured, revision-friendly repository tracking my journey through **Data Structures & Algorithms in Python** — geared toward coding-interview preparation and becoming a stronger engineer.

---

## 📖 How this repo is organized

Each topic has its own folder containing:

- **Notes** (`.md`) — explanations, complexity tables, patterns, Python gotchas
- **Examples** (`.py`) — runnable Python code demonstrating each concept
- **Problems** (in `problems/`) — solved interview-style problems with notes

```
.
├── 01-foundations/            # Big-O, recursion fundamentals
├── 02-linear-structures/      # Arrays, strings, linked lists, stacks, queues, hash tables
├── 03-non-linear-structures/  # Trees, heaps, tries, graphs
├── 04-algorithms/             # Searching, sorting, DP, greedy, graph algorithms
├── 05-patterns/               # Two-pointer, sliding window, backtracking, etc.
├── problems/                  # Solved problems organized by difficulty
└── cheatsheets/               # Quick-reference cheatsheets
```
