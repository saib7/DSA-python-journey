# 📝 Problems

Solved interview-style problems, organized by difficulty and pattern.

---

## Structure

```
problems/
├── easy/
├── medium/
└── hard/
```

Each problem lives in its own folder:

```
problems/easy/two-sum/
├── README.md       # Problem statement + my approach + notes
├── solution.py     # My solution
└── tests.py        # (optional) test cases
```

---

```markdown
# Problem Title

- **Pattern:** Two-Pointer / Hash Map / DP / Sliding Window / ...
- **Source:** [LeetCode #N](https://leetcode.com/problems/...)

## Problem

(short description in your own words)

## My Approach

(your thinking — not just the solution)

1. First I considered ...
2. The brute force would be ...
3. The optimization came from ...

## Complexity

- **Time:** O(...)
- **Space:** O(...)

## Key Insight

(the one idea that made this click — what to remember for similar problems)

## Mistakes / Lessons

(what tripped you up, edge cases you missed, etc.)
```
